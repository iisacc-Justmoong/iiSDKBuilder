# 빌드와 테스트 파일 배치

모듈과 실행 파일의 컴파일 산출물은 `build/`에 둔다. 빌드 매니페스트와 입력 리소스는 프로젝트의 `resources/`에 둔다.

파일을 생성하는 CTest는 iiFileProvider로 `resources/.state/` 아래에 호출마다 고유한 임시 작업 공간을 만든다. 테스트, 통합 빌드 또는 설치 소비자 검증의 파일은 그 안에서 사용하며, 프로세스가 정상적으로 돌아오거나 예외가 발생하면 삭제한다. 갑작스러운 강제 종료는 운영체제가 정리를 보장하지 않으므로 남은 작업 공간을 확인한 뒤 제거한다. 병렬 테스트는 서로 다른 작업 공간을 사용한다.

테스트 시간 제한은 기존 값을 유지한다. HLS 하드웨어 동등성 검사는 관련 도구가 준비된 경우에만 등록된다. CLI·플랫폼 또는 실제 기기 실행 결과는 단위 테스트 통과와 구분한다. 설치 패키지는 외부 경로에 두며 `build/`를 임시 설치 저장소로 사용하지 않는다.
